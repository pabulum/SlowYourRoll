▸ How the math works

Each source shows the expected value of one bonus-roll token spent on it:

EV = ( Σ value of wanted items ÷ items still in pool ) ÷ token cost

Values come from your own tool — QE Live for healers, a sim for DPS/tanks. Enter whatever number that gives you; the tool just ranks them. Every item is one of three states:

WantAn upgrade still in the pool. Its value counts toward EV.
OwnYou took it from your vault. It stays in the bonus-roll pool (taking a vault item doesn't remove it) so it dilutes your odds, but it's worth 0 to you now — the trap the guide warns about.
RolledYou bonus-rolled it. Gone from the pool for good — drops out of both the value and the pool count.

Pool size is every item that can still drop from that source (upgrades + junk). Junk rolled tracks rolls that hit an item you never listed, so the pool still shrinks. Token cost is 1 for everything in S2 — set it to 2 for S1-style raid rolls (that's the ÷2 from your notepad).
